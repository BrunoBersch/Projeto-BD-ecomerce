Este projeto consiste na modelagem e implementação de um banco de dados relacional para um sistema de e-commerce. O objetivo é organizar e 
  armazenar informações relacionadas a clientes, produtos, pedidos, pagamentos, estoques, fornecedores e vendedores.

O banco de dados é composto pelas seguintes tabelas:

Cliente: Armazena dados de clientes (Pessoa Física ou Jurídica).
Produto: Informações sobre os produtos disponíveis.
Pedido: Detalhes dos pedidos realizados.
Pagamento: Informações sobre os pagamentos dos pedidos.
Estoque: Localização e quantidade de produtos disponíveis.
Fornecedor: Dados dos fornecedores dos produtos.
Vendedor: Informações dos vendedores (Pessoa Física ou Jurídica).
Vendedor_produtos: Relação entre vendedores e os produtos que vendem.
Estoque_de_produtos: Relação entre produtos e estoques.
Fornecedor_produto: Relação entre fornecedores e produtos fornecidos.
Produto_do_pedido: Produtos incluídos em cada pedido.
